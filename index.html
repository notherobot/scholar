In LM Studio: Developer → Server Settings → Require Authentication, then Manage Tokens. Default port 1234.

Comma-separated. A server from LM Studio's mcp.json is mcp/<label> — the label is whatever you named it there. A plugin from the Hub is <owner>/<name>. LM Studio has no way to list these over the API, so they have to be typed.

These are attached to every message, with no on/off switch — the model calls them when it decides to. In LM Studio also turn on Server Settings → Allow calling servers from mcp.json.
